# 學生用免登入的分享連結看唯讀看板，並顯示完整名稱

狀態：proposed。

學生需要親眼確認自己的 Agent 是否預約成功，但不該為了看一頁再登入一次。教師後台為目前堂課產生分享連結（長隨機碼），拿到連結就能看，不必登入；頁面唯讀、自動更新，不能預約或取消，預約只能經由學生自己的 Agent。頁面顯示完整的顯示名稱，學生才認得出自己。連結 12 小時後自動失效，教師可隨時重新產生（舊連結立即失效）或關閉。教師後台與完整監看頁仍要教師登入。

## Considered Options

- **學生以 router 登入後看自己的看板（可標「我的預約」）**：放棄，學生多一個登入步驟。
- **分享頁遮蔽名稱或只顯示「已借」**：放棄，學生分不出哪一格是自己的。

## Consequences

- 連結外流時，名單一起外流；Google 學生的顯示名稱通常是真名，課堂上建議用暱稱兌換。
- 頁面不知道看的人是誰，無法標出「我的預約」。
