# 規格 v1｜社團教室出借看板＋Agent API

- **狀態**：定稿候補審｜2026-09-18｜產品規格助手
- **技術棧**：未定（交前後端／幕僚長另決）
- **Notion 草稿**：[規格 v1｜社團教室出借看板＋Agent API](https://app.notion.com/p/3df60fdf66578180a453c6fc69f5511a)

## 目標

讓學生在課堂用建好的 agent，透過 API 查詢、預約、取消「社團可借教室」；教師為每一堂課設定可借資源，預約／取消結果即時顯示在時間表式看板上。另提供 API 產生宣傳海報**文案**（不出圖）。

## 角色

| 角色 | 職責 |
|------|------|
| 教師 | 每堂課設定可借清單；監看看板即時結果 |
| 學生（經 agent） | 查可借、預約、取消自己的預約；產生海報文案 |

## 資源模型

可借單位＝**日期 + 時段 + 教室編號**（例：9/25、13:00–15:00、教室 301）

- 每天可有多個時段；每時段可有多間教室
- 教室必須有可辨識編號（課堂上好讀）
- 教師以「每一堂課」為單位開出可借清單

## 使用者故事

1. 教師可為「這一堂課」設定哪些「日＋時段＋教室」可借
2. 學生可透過 agent 查目前可借清單（含日期、時段、教室編號）
3. 學生可透過 agent 預約某一可借格；成功後看板上出現該筆
4. 學生可透過 agent 取消**自己的**預約；格子釋出後可再被預約
5. 教師可在看板上近即時看到預約／取消結果（誰／哪一格）
6. 學生可透過 agent 依活動資訊產生海報文案（標題、時間地點、slogan、內文等結構）
7. 多人／多 agent 同時搶同一格時，只能有一筆成功，其餘明確失敗（防 race condition）

## 範圍（v1）

- 堂課級：設定／列出可借（日＋時段＋教室編號）
- Agent API：查詢可借、預約、取消自己的預約
- 時間表式看板：可借格＋已預約結果，近即時更新
- 併發產品規則：同一「日＋時段＋教室」同時僅允許 **1** 筆成功預約
- 海報文案 API：輸入活動資訊 → 回傳文案結構（**不出圖**）

## 不做（本版）

- 海報出圖、複雜審核流、完整帳號權限體系
- 技術棧選定與綁定
- 教師從看板「強制取消他人預約」（若需要可另開）

## 驗收條件

- 查詢只回該堂課已開出的「日＋時段＋教室」
- 預約須指定完整三元组；成功後看板短時間內出現該筆
- 已被借走的格子不可再預約成功
- 取消成功後該格可再被預約；取消不存在／非本人預約須明確失敗
- **併發**：對同一格同時送 N 筆預約，恰好 1 成功、其餘失敗且錯誤可被 agent 理解（如「已被預約」）
- 看板近即時反映預約與取消（可接受自動刷新）
- 海報 API 依輸入回傳可用文案結構，不含圖檔
