# 堂課掛在 router 班級下，沒有「開放預約」開關

狀態：proposed。

學生的課堂金鑰只說明他屬於哪個班級、哪次上課，所以每個堂課屬於一個 router 班級，每個班級有一個目前堂課（新建即成為目前堂課，教師可切回舊的）。學生不指名堂課，一律進入自己班級的目前堂課；Agent 不必知道堂課 id，也就不會填錯。

學生能否預約跟著課堂金鑰的時效：上課前 router 回「尚未開始」、下課後回「已過期」，本系統不再有開放／關閉開關。唯一保留的是暫停，預設不暫停，讓教師上課中只擋預約與取消、不影響 LLM 與 vans；查詢照常。班級沒有任何堂課或已暫停時回 403 `BOOKING_CLOSED`，以訊息區分。

## Considered Options

- **堂課直接綁 router 的課堂（Class Session）**：放棄，router 只告訴後台教師有哪些班級，列不出課堂；且一堂課的可借清單常跨到之後的日期。
- **保留獨立堂課 id，由教師投影給學生寫進提示詞**：放棄，多一個會填錯的參數。
- **保留「開放預約」開關**：放棄，與金鑰時效重複；要停整堂課就在 router 結束課堂。

## Consequences

- 下課後學生的金鑰失效，不能再取消自己的預約；需要時由教師在後台強制取消。
