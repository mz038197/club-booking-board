# 規格 v1｜社團教室出借看板＋Agent API

- **狀態**：定稿候補審｜2026-09-18｜產品規格助手
- **技術棧**：未定（交前後端／幕僚長另決）
- **Notion 草稿**：[規格 v1｜社團教室出借看板＋Agent API](https://app.notion.com/p/3df60fdf66578180a453c6fc69f5511a)

> **部分已被取代（2026-11-13）**：身分、堂課與學生看板的部分改依下列 ADR，與本規格衝突時以 ADR 為準。
> - [ADR 0003](../adr/0003-identity-comes-from-the-router.md)：學生從 `Authorization: Bearer` 的 router 課堂金鑰取得身分，介面不再收 `student_id`；教師以 router Google 登入。取代本規格「不做：完整帳號權限體系」。
> - [ADR 0004](../adr/0004-session-belongs-to-a-class-without-an-open-switch.md)：堂課掛在 router 班級下，學生介面不帶 `session_id`，一律進入班級的目前堂課；沒有開放開關，只有暫停（`BOOKING_CLOSED`）；教師可強制取消。取代下方「對齊契約」中學生介面的路徑。
> - [ADR 0005](../adr/0005-students-see-the-board-through-a-share-link.md)：學生以免登入的分享連結看唯讀看板。

## 目標

讓學生在課堂用建好的 agent，透過 API 查詢、預約、取消「社團可借教室」；教師為每一堂課設定可借資源，預約／取消結果即時顯示在時間表式看板上。另提供 API 產生宣傳海報**文案**（不出圖）。

## 角色

| 角色 | 職責 |
|------|------|
| 教師 | 每堂課設定可借清單；監看看板即時結果 |
| 學生（經 agent） | 查可借、預約、取消自己的預約；產生海報文案 |

## 資源模型

可借單位＝**日期 + 時段 + 教室編號**（例：9/25、13:00–15:00、教室 301）

- 每天可有多個時段；每時段可有多間教室
- 教室必須有可辨識編號（課堂上好讀）
- 教師以「每一堂課」為單位開出可借清單

## 使用者故事

1. 教師可為「這一堂課」設定哪些「日＋時段＋教室」可借（整批覆寫該堂課可借清單）
2. 若新清單會拿掉**已有預約**的格子，系統拒絕並保留原清單（不可默默刪掉已借格）
3. 學生可透過 agent 查目前可借清單（含日期、時段、教室編號）
4. 學生可透過 agent 預約某一可借格；成功後看板上出現該筆
5. 學生可透過 agent 取消**自己的**預約；格子釋出後可再被預約
6. 教師可在看板上近即時看到預約／取消結果（誰／哪一格）
7. 學生可透過 agent 依活動資訊產生海報文案（標題、時間地點、slogan、內文等結構）
8. 多人／多 agent 同時搶同一格時，只能有一筆成功，其餘明確失敗（防 race condition）

## 範圍（v1）

- 堂課級：教師以 **PUT** `/sessions/{session_id}/slots` 設定可借清單；請求體 `{ slots: [{ date, start, end, room }] }`，對該堂課可借格**整批覆寫**
- 已借格保護：新清單若會移除已有預約的格子 → **CONFLICT**，不寫入
- Agent API：查詢可借／看板、預約、取消自己的預約
- 時間表式看板：可借格＋已預約結果，近即時更新
- 併發產品規則：同一「日＋時段＋教室」同時僅允許 **1** 筆成功預約
- 海報文案 API：輸入活動資訊 → 回傳文案結構（**不出圖**）

## 不做（本版）

- 海報出圖、複雜審核流、完整帳號權限體系
- 技術棧選定與綁定
- 教師從看板「強制取消他人預約」（若需要可另開）——**已被 ADR 0004 取代**：教師可在後台強制取消

## 驗收條件

- 教師 PUT 可借清單後，查詢／看板只見該堂課這批「日＋時段＋教室」
- 新清單會移除已有預約的格子時回 **CONFLICT**，原清單與預約不變
- 預約須指定完整三元组；成功後看板短時間內出現該筆
- 已被借走的格子不可再預約成功
- 取消成功後該格可再被預約；取消不存在／非本人預約須明確失敗
- **併發**：對同一格同時送 N 筆預約，恰好 1 成功、其餘失敗且錯誤可被 agent 理解（如「已被預約」）
- 看板近即時反映預約與取消（可接受自動刷新）
- 海報 API 依輸入回傳可用文案結構，不含圖檔

## 對齊契約（實作者備忘）

產品語意已對齊；路徑與錯誤碼供實作對齊，非 OpenAPI。

- `slot_id`：`{date}_{start}-{end}_{room}`
- 教師寫入：`PUT /sessions/{session_id}/slots`，body `{ slots: [{ date, start, end, room }] }`（整批覆寫；已借格被拿掉 → `CONFLICT`）
- 看板：`GET /sessions/{session_id}/board`
- 預約：`POST /sessions/{session_id}/bookings`；取消：`DELETE` 該筆預約（僅本人）
  - **已被 ADR 0003／0004 取代**：學生介面不帶 `session_id`、不收 `student_id`，身分來自 Bearer 課堂金鑰；新增 401（金鑰無效、過期、課堂未開始）與 403 `BOOKING_CLOSED`。新路徑待新版規格定案。
- 海報：`POST /poster/copy`（只出文案、不出圖）
- 錯誤碼：`SLOT_TAKEN`、`NOT_OWNER`、`NOT_FOUND`、`INVALID_SLOT`、`INVALID_POSTER`、`INVALID_REQUEST`、`CONFLICT`
  - `INVALID_SLOT`：格子格式／未知格子
  - `INVALID_POSTER`：海報文案請求驗證失敗
  - `INVALID_REQUEST`：其他請求驗證失敗
- 併發：`UNIQUE (session_id, slot_id)` → `SLOT_TAKEN`
